Introduction

This blog post explores the beer_markets dataset, which contains information about beer purchases, pricing, packaging, geographic markets, and household demographics.

The analysis focuses on patterns in consumer beer purchasing behavior, including how beer volume, promotions, brands, and household characteristics relate to beer spending and pricing.

library(tidyverse)

beer_markets <- read_csv(
  "https://bcdanl.github.io/data/beer_markets_all_cleaned.csv"
)

Regression models

model1 <- lm(
  log(price_floz) ~
    market +
    brand +
    container +
    log(beer_floz),
  data = beer_markets
)

model2 <- lm(
  log(price_floz) ~
    market +
    brand +
    container +
    log(beer_floz) +
    brand:log(beer_floz),
  data = beer_markets
)

library(stargazer)

stargazer(
  model1,
  model2,
  type = "text"
)
